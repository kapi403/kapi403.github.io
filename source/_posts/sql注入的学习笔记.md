# 关于sql注入的学习1
## 对于注入的一些常用套路和原因
**根本原因是因为把用户的输入直接拼接到了语句中**
具体需要先判断这个语句是啥样，我目前见到的有存在一个输入框，或者在url里面输入，一般后缀是id=,当我们确定是注入之后**开始判断类型**
## 判断具体形式
最容易的就是先看是数字形还是字符型，简单来说就是输入数字还是输入字符，像moectf的那个河湖小盗和它的进阶题都是数字型
，然后我们需要去试探它需要啥样的，因为对于一个语句，你输入的地方可能是id="输入"，也可能是id='输入'，假如我们输入1'，那么在第一种显示的就是"1'",明显有问题，那我们就需要输入1",结果就是"1"", 对于前面两个双引号构成了一个闭合，后面多了一个双引号，那就注释掉它，也就是#或者\这种，至于直接输入1，那自然没有问题，可是那样就没办法达成我们的目的，也就是获取信息，**那就涉及到关键的一个地方， *拼接的语句***需要先把前面的包含住（具体原因我现在也不清楚，我就一新手，等后面补上）
## 拼接语句
也就是在前面的输入的后面写下自己要执行的语句，因为语法是直接把你输入的拼接进去，导致后面输入的也同样被拼接了，那么就涉及到非常重要的一个东西，union和select和一些数据库的基本信息，还要先拼接一个东西先确定确实执行你的语句了**一般是加or true或者or 1=1（记得加注释的符号）**
**一个小小的分类（bushi）**我们还需要确定这个网页到底有没有显示，也就是显示执行你的语句之后，输出东西的地方，如果没有，那么很~~幸运~~，我们碰到盲注了（具体类型还需要判断，具体有啥可以参考[helloctf的web的sql注入]（https://hello-ctf.com/hc-web/sql_injection/）
## 具体操作
前缀大概就这些了，**现在开始讲~~应试~~的了(先不讲盲注的区别)**
当我们确定是数字型之后，我们要进行第一步，确定显示的地方有多少，也就是在前面的数字拼接，例如**1' order by 1**,同样的句子，把1往上加就ok，一直加到你输入并回车后页面报错或者和之前不一样，我现在假设是到3，那也就是有3个位置，然后我需要用语句去确定这三个位置哪个是可以显示出来的，也就是**1' union select 1,2,3**然后看显示出来了哪个数字，下一步就在哪个数字位置写，*例如我这里就在1*，那么我们就开始下一步
1' union select database(),2,3 ~~这个非常有用啊（bushi）~~,这句话是让我们找到了现在我们所在的库的名字，有时候不一定有用，看自己习惯吧，**下一步**，我们找到了库名，那现在就需要去找表名了（记得去提前看看数据库啥样子）,这里我们使用一些新的语句，group_concat(),information_schema.tables,前一个是对于输出的结果类似一个排序吧，不要也可以。就是可能有问题，~~反正顺便就记住了~~，后一个的话就是一个语法吧，就像c语言里面的printf（不一定），直接记住前面的information.schema就行，这个schema倒是可以理解成库，（因为库名是schema_name）也就是1' union select group_concat(table_name),2,3 from information_schema.tables where table_schema=database() **information_schema.tables**这个大概意思就是表的数据，就是意思是从表这个等级里面找table_name这个东西，**table_schema=database()**这个我的理解就是去限定是在某个特定的库里面的表，不然把所有表都拿到一起了，*下一步*，现在这里我们知道了表的名字，我们需要知道表的内容了啊，还是一样的逻辑，只是把table改成column而已，**（记得注意哪个雷霆大s~~我已经忘记了很多次了~~）**
如果表不是很多你甚至可以不限定在哪个表里面找列名，只限制一下数据库就好，一般还是限制一下吧，~~当然我目前写过的几个我都没有限制过~~例如有一个表名叫flag_table，
那就是1' union select group_concat(column_name) from information_schema.columns where                column_schema=flag_table或者你用table_schema=database()也可以就是有点多
那现在我们知道了库知道了表知道了列，就找列的数据就行了，ctf里一般有flag这个列名，我假设是flag_table这个表名吧，那最后就是1' union select flag,2,3 from flag_table,现在结果就出来了
### 对于盲注，简单来说就是没有显示，就是说，除了设定好的以外不显示其他的，也就是说我们即使能让它输出自己的数据库内容，但是没有显示的地方，那具体做法就是让它执行判断语句，看每一位是不是某个字母，就是从a到z，看是否有正确回应就好，具体的看下一篇吧
